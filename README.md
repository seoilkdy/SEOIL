# 갓생살기 - 대학생 생산성 도구

**갓생살기**는 대학생의 알찬 학교생활을 돕기 위해 제작된 파이썬(Tkinter) 기반의 데스크톱 애플리케이션입니다.  
할 일 관리, 발표 타이머, 성과 리포트, 그리고 **학교 공지사항 대시보드**와 **AI 코칭 도우미** 기능을 하나의 앱에서 제공합니다.

***

## ✨ 주요 기능

### 1. 🏫 대시보드 (Dashboard)
학교 홈페이지의 정보를 실시간으로 크롤링하여 한눈에 보여줍니다.
- **학사공지**: 학교의 최신 학사 공지사항을 리스트로 확인하고, 더블클릭하여 바로 브라우저로 이동합니다.
- **취업정보**: 소프트웨어공학과의 최신 취업 정보를 제공합니다.
- **학사일정**: 캘린더 형태로 월별 학사 일정을 시각적으로 확인하고 필터링할 수 있습니다.

### 2. ✅ 할 일 관리 (Todo)
- **체계적 관리**: 제목, 기간, 상세 설명, 상태(미완료/진행중/완료)를 관리합니다.
- **D-DAY 자동 표시**: 마감일까지 남은 시간을 `D-3`, `D-DAY`, `지남` 등으로 직관적으로 보여줍니다.
- **간편한 조작**: `Space` 키로 상태 변경, `Delete` 키로 삭제, 더블클릭으로 상세 편집이 가능합니다.

### 3. ⏱️ 발표 타이머 (Timer)
- **발표 연습 최적화**: 발표 시간(분)과 경고 임계 시간(초)을 설정할 수 있습니다.
- **시각적 피드백**: 남은 시간이 임계값 이하로 떨어지면 주황색, 종료 시 빨간색으로 깜박이며 알림을 줍니다.
- **진행률 바**: 시간의 흐름을 시각적인 바(Bar) 형태로 확인할 수 있습니다.

### 4. 📊 성과 리포트 (Report)
- **주간 히트맵**: 요일별 활동량을 색상으로 시각화하여 보여줍니다.
- **통계 분석**: 완료율, 평균 소요 기간, 마감 임박/지남 건수 등을 분석해줍니다.
- **시각화**: 도넛 차트와 스택 바를 통해 성취도를 직관적으로 파악할 수 있습니다.

### 5. 🤖 AI 코칭 도우미 (Assistant)
- **숨겨진 도우미**: 우측 하단의 `✨ 도우미` 버튼이나 `Ctrl+K` 단축키로 호출합니다.
- **컨텍스트 인식**: 현재 할 일 목록과 리포트 상태를 분석하여, "지금 바로 해야 할 일"을 추천해줍니다.
- **맞춤 조언**: 발표 타이머 시작 시 마무리 멘트를 제안하거나, 일정 관리에 대한 실질적인 조언을 제공합니다.

## 🛠️ 설치 및 실행 방법

### 요구 사항
- Python 3.10 이상
- 인터넷 연결 (공지사항 크롤링 및 AI 기능용)

### 실행
```bash
# 1. 필수 라이브러리 설치 (필요 시)
# (표준 라이브러리 외에 openai 모듈이 필요할 수 있습니다)
pip install openai

# 2. 앱 실행
python main.py
```

> **참고**: AI 기능을 100% 활용하려면 `OPENAI_API_KEY` 환경 변수 설정이 필요합니다. 키가 없어도 기본 기능(할 일, 타이머, 대시보드)은 정상 작동하며, AI 기능은 로컬 규칙 기반의 폴백(Fallback) 모드로 동작합니다.

***

## 🗂️ 프로젝트 구조

- `main.py`: 애플리케이션의 진입점(Entry Point)이자 메인 윈도우 관리
- `core.py`: 공통 상수, 유틸리티 함수, DB 연결 관리
- `tab_dashboard.py`: 대시보드 탭 (크롤링, 캘린더 로직)
- `tab_todo.py`: 할 일 관리 탭
- `tab_timer.py`: 타이머 탭
- `tab_report.py`: 리포트 및 통계 탭
- `app_old.py`: (Legacy) 이전 버전 백업 파일

***

## ⌨️ 단축키

| 키 (Key) | 동작 |
| --- | --- |
| **Enter** | 할 일 빠른 추가 |
| **Space** | 할 일 상태 변경 (미완료 ↔ 진행중 ↔ 완료) |
| **Delete** | 선택한 할 일 삭제 |
| **Double Click** | 상세보기 / 편집 / 링크 열기 |
| **Ctrl + K** | AI 도우미 팝업 열기/닫기 |
